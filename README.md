# Databricks FinOps Lakehouse

Enterprise FinOps and IT Asset Management analytics platform built using:

- Databricks
- Delta Lake
- Unity Catalog
- Terraform
- Databricks Asset Bundles
- GitHub Actions

## Architecture

GitHub
→ GitHub Actions
→ Asset Bundles
→ Databricks

Bronze
→ Silver
→ Gold

→ Executive Dashboard

## Business Goals

- Identify cloud waste
- Detect underutilized resources
- Track software license optimization opportunities
- Analyze downtime costs
- Generate FinOps KPIs
